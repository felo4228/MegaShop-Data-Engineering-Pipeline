MegaShop Data Engineering Pipeline

An end-to-end Data Engineering project that simulates the migration of a legacy Excel/CSV-based sales system into a modern Big Data architecture using Python, Dask and PySpark.
This project demonstrates ingestion, distributed ETL processing, data warehousing with Parquet, visualization, and real-time streaming analytics.

Project Overview

Company: MegaShop

MegaShop stores massive historical sales data, but the legacy system based on Excel and CSV files cannot scale anymore.
The goal of this project is to design and implement a modern data pipeline capable of handling large datasets using Big Data tools.

Technologies Used:

- Python
- Pandas
- Dask
- PySpark
- Parquet
- Matplotlib
- Seaborn
